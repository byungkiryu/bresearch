Zotero CSV를
홈페이지에 올릴 준비

Zotero에서 내보낸 원본 CSV를 선택하면 홈페이지에 쓰는 17개 열만 남깁니다. 선택한 파일은 이 브라우저 안에서 처리하며, 원본 파일은 바뀌지 않습니다.

  1. Zotero에서 논문·발표를
    CSV로 내보내기
  2. 아래에서 원본 선택 후
    준비된 CSV 다운로드
  3. GitHub 저장소의 input/에
    같은 이름으로 업로드
01 / PUBLICATIONS

논문 CSV

논문·도서·학술자료의 제목, 전체 저자, DOI, 태그 등을 유지합니다.

파일을 선택하면 기록 수와 제외한 열 수가 표시됩니다.

02 / PRESENTATIONS

발표 CSV

발표 제목, 전체 저자, 학회명, 장소, 날짜와 발표 유형을 유지합니다.

논문과 발표 중 필요한 파일만 준비해도 됩니다.

공개할 내용을 한 번 확인하세요.
Notes, Extra, 첨부파일 열과 PC의 파일 경로가 들어가는 첨부정보는 제외합니다. URL 열도 http·https 웹 주소만 유지합니다. 제목·저자·태그 등 남겨진 17개 열의 내용은 GitHub에 업로드하면 공개됩니다. 이 도구는 남겨진 문장 속 개인정보까지 찾아 지우지는 않습니다.

인터넷 연결 없이 사용할 수 있습니다. 파일을 서버로 전송하지 않으며, 준비된 CSV는 UTF-8 BOM 형식으로 저장됩니다. Zotero Key는 그대로 유지합니다.
