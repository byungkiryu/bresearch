## 자동 동작 검사

표준 Python `unittest`로 15개 동작 검사가 통과했습니다.

- CSV 재내보내기와 순서 변경 때 기존 ID 유지
- DOI가 유일한 경우 새 Zotero Key를 기존 홈페이지 ID에 재연결
- 과거 Key가 다시 나타날 때도 같은 ID 유지
- 중복 DOI·Key 및 미확인 DOI 변경 차단
- 발표 재연결을 명시적으로 지정한 경우 같은 ID 유지
- 같은 제목의 Oral·Poster 발표 분리
- CSV에 없는 항목의 마지막 정보와 ID 보존
- 별도 해설·그림 연결 파일 보존
- 메모·첨부파일 경로 등 비공개 원본 열 제외
- 월 단위 날짜 보존과 페이지 결측 처리
- 검토 후 승인한 DOI 정정 이력 기록
- 비슷한 후보가 있어도 별개 항목으로 승인하면 새 ID 부여
- registry 유실 상태에서 ID 재생성 차단

## 범위

이 검증은 데이터 변환과 연결 유지에 관한 것입니다. 실제 Zotero 계정 연동, 웹페이지 표시, GitHub 업로드, GitHub Pages 배포는 아직 포함하지 않습니다. 향후 공개 화면에서는 JSON의 텍스트를 HTML로 실행하지 않고 텍스트로 표시해야 합니다.
